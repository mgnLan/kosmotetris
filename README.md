# 🚀 КосмоТетрис (VK Mini Apps)

> Космическая версия классического Тетриса в стиле VK Mini Apps с системой монетизации.

---

## 📋 Описание проекта

**КосмоТетрис** — это адаптация классического Тетриса в научно-фантастической космической тематике. Игра оформлена в стиле VK Mini Apps: карточный интерфейс, синяя палитра, таблица лидеров, социальные функции.

### Особенности
- 🌌 Мерцающее звёздное поле на фоне
- 🎨 Неоновые космические блоки с glow-эффектом
- 👻 Призрачная фигура для точной посадки
- 🏆 Таблица лидеров (топ-5, сохраняется в localStorage)
- 🎭 Превью следующей фигуры
- 📱 Адаптивные тач-контролы (56×56 px)
- 💬 Кнопка «Поделиться» при новом рекорде

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| ← / → | Перемещение фигуры |
| ↑ | Поворот |
| ↓ | Ускорить падение (+1 очко) |
| Пробел | Мгновенное падение (hard drop) |
| P | Пауза / продолжить |

Тач-контролы доступны на экране для мобильных устройств.

---

## 🚀 Запуск

### Локально
Просто откройте файл `game.html` в браузере. Никаких зависимостей не требуется — всё inline.

### VK Mini Apps
1. Зарегистрируйте приложение в [VK Dev](https://dev.vk.com/)
2. Загрузите `game.html` как статический хостинг
3. Подключите VK Bridge для нативных функций (Stars, реклама, шаринг)
